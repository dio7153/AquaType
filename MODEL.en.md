# AquaType Model Card

[中文](MODEL.md) | **English**

This document describes the two models included in AquaType 0.9.0: the Zhuyin model and the language model.

## Model details

- **Developer:** Dio Hsieh
- **Version:** AquaType 0.9.0
- **Purpose:** Convert Zhuyin keystrokes into Traditional Chinese text, and suggest the right words when keys are mistyped
- **Language:** Traditional Chinese (Taiwan)
- **License:** [CC BY-NC 4.0](https://creativecommons.org/licenses/by-nc/4.0/), non-commercial use only
- **Base model:** None. Both models were trained from scratch, without any pretrained model or external weights
- **Source code:** This repository

## Architecture

AquaType uses two models:

- **Zhuyin model:** Reads the whole key sequence, scores every way to split it into Zhuyin syllables, and estimates the likely character at each position.
- **Language model:** Scores, one character at a time, how natural each candidate reads.

| | Zhuyin model | Language model |
|---|---|---|
| Architecture | Bidirectional Transformer encoder | Autoregressive Transformer (decoder only) |
| Parameters | About 176 million | About 16.3 million |
| Layers / width / attention heads | 12 / 1024 / 16 | 6 / 384 / 6 |
| Input | Zhuyin keystrokes (44 keys) | Traditional Chinese characters |
| Output | Probabilities over 1,784 Zhuyin syllables and 14,513 characters | Probability of the next character (14,517-token vocabulary) |
| Numeric format | 4-bit quantized (linear layers) | 16-bit floating point |

Together the two models take up about 136 MB. They run on Apple silicon with [MLX](https://github.com/ml-explore/mlx) and don't need a network connection.

## Uses

**Intended use**

- Entering Traditional Chinese with the standard Zhuyin keyboard layout in AquaType.
- Suggesting the words the user meant to type when keys are mistyped.

**Out-of-scope use**

- Generating text or conversation. The models only score candidates for the keys the user typed; they don't produce content on their own.
- Simplified Chinese, Hanyu Pinyin, or keyboard layouts other than standard Zhuyin.
- Commercial use. The license permits non-commercial use only.

**Training procedure**

- The Zhuyin keystrokes used for training were converted from text by pronunciation. No input from real users was used.
- When training the Zhuyin model, about three quarters of the sentences had mistyped, missed, extra, or swapped adjacent keys simulated by rules, with each key's chance of an error between 0% and 60%. The language model was trained on text only.
- The Zhuyin model was trained for 380,000 steps, and the language model for 200,000 steps.
- Before training, sentences identical to a test sentence, or sharing a run of 8 characters with one, were removed.

## Evaluation

**Test data:** The test set has 4,049 sentences, drawn from the same data sources by sentence length and set aside before training. Sentences identical to a test sentence, or sharing a run of 8 characters with one, were removed from the training data; a check after training found no duplicates.

The test set isn't published: some of its sentences come from sources that don't allow redistribution, and keeping it unpublished allows later versions to be compared fairly.

**Method:** Each key has a set chance of being simulated as mistyped, missed, extra, or swapped with an adjacent key. Personal memory and preceding text aren't used.

**Metrics:** The share of sentences whose full correct sentence is the first suggestion, in the top 9 (the first page), and in the top 64.

**Results**

600 sentences drawn at random from the test set, with the settings AquaType 0.9.0 uses for real input:

| Mistyped keys | Correct result first | Correct result in top 9 | Correct result in top 64 |
|---|---|---|---|
| 0% | 78.7% | 94.3% | 97.3% |
| 20% | 52.8% | 75.8% | 84.2% |
| 40% | 33.5% | 51.7% | 63.7% |

**Summary:** With no mistyped keys, the correct sentence appears on the first page about 94% of the time. The more keys are mistyped and the longer the sentence, the more likely it is that the correct result isn't among the suggestions.

## Bias, risks, and limitations

- The training data includes a large amount of forum text (PTT, Dcard) and some conversations generated by language models, so the models' choice of characters and words leans toward these sources.
- The longer the sentence, or the more keys are mistyped, the more likely it is that the correct result isn't among the suggestions.
- Some colloquial characters and less common words are predicted less often and may appear lower in the suggestions.
- Domains, proper nouns, or new words that are rare in the training data may not be converted correctly.
- The mistyped keys in the evaluation are all simulated by rules; the models haven't been evaluated on typing data from real users. The test sentences come from the same sources as the training data, so performance in real use may differ.

**Recommendations:** When the correct result isn't among the suggestions, press Tab to choose words one segment at a time. AquaType's personal memory remembers the words you choose and suggests them first next time.
