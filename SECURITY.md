# 安全性

## 支援的版本

只有最新發布的版本會收到安全性修正。

| 版本 | 支援 |
|---|---|
| 0.9.x | ✅ |

## 回報安全性問題

如果你發現 AquaType 的安全性問題，請不要在 Issues 中公開回報。

請前往這個 repository 的「Security」分頁，按一下「Report a vulnerability」，透過 GitHub 私下回報。回報時請附上：

- 問題的內容與可能的影響
- 重現步驟
- 受影響的 AquaType 與 macOS 版本

## 處理方式

- 確認問題後，會在修正版本發布時公開說明，並在你同意下致謝。
- 在修正發布前，請不要公開問題的細節。

# Security

## Supported versions

Only the latest release receives security fixes.

| Version | Supported |
|---|---|
| 0.9.x | ✅ |

## Reporting a vulnerability

If you find a security issue in AquaType, please don't report it publicly in Issues.

Go to the Security tab of this repository, click "Report a vulnerability", and report it privately through GitHub. Include:

- What the issue is and its possible impact
- Steps to reproduce it
- The affected AquaType and macOS versions

## What to expect

- Once the issue is confirmed, it will be disclosed when the fix is released, and you'll be credited if you wish.
- Please don't share details of the issue publicly until a fix is released.
